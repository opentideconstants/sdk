# OpenTideConstants SDKs

Client libraries for [OpenTideConstants](https://opentideconstants.org), an open dataset of tidal harmonic constants: Ruby, Python, TypeScript/JavaScript and C.

**Status: not released.** The packages on RubyGems, PyPI and npm are `0.0.0` placeholders that reserve the name `opentideconstants`. They contain no SDK code.

- `ruby/`, `python/`, `js/`: the placeholder packages.
- `.github/workflows/placeholder-pypi.yml`: publishes the Python placeholder with PyPI trusted publishing (run it by hand).
